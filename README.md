# Eskom Smart Electricity System

## Evaluation and Improvement Proposal for an Existing Information System

This project evaluates the Eskom electricity outage, fault reporting, metering & customer management system and proposes improved solutions.

### Project Structure

- **Frontend**: React-based user interface
- **Backend**: Node.js/Express REST API
- **Documentation**: Complete project deliverables

### Quick Start

#### Frontend
```bash
cd frontend
npm install
npm start
```

#### Backend
```bash
cd backend
npm install
npm start
```

### Project Deliverables

1. Introduction
2. Literature Review
3. System Evaluation
4. Gap Analysis
5. Proposed Solution
6. Project Management Plan
7. System Design
8. Final Evaluation Report

### Technologies Used

- **Frontend**: React.js, Material-UI, Axios
- **Backend**: Node.js, Express.js, MongoDB/PostgreSQL
- **Database**: MongoDB/PostgreSQL
- **Authentication**: JWT
- **Documentation**: LaTeX/Markdown
