# Eskom Smart Electricity System - Setup Instructions\n\n## Quick Start Guide\n\n### System Requirements\n- Node.js 18+ \n- MongoDB 6.0+\n- Git\n- npm or yarn\n- 4GB RAM minimum\n- 10GB disk space\n\n---\n\n## STEP 1: Clone the Repository\n\n```bash\ngit clone https://github.com/24071829/Eskom-Smart-Electricity-System.git\ncd Eskom-Smart-Electricity-System\n```\n\n---\n\n## STEP 2: Install MongoDB\n\n### Windows\n1. Download from: https://www.mongodb.com/try/download/community\n2. Run installer\n3. Select \"Install MongoDB as a Service\"\n4. MongoDB runs on localhost:27017\n\n### Mac\n```bash\nbrew tap mongodb/brew\nbrew install mongodb-community\nbrew services start mongodb-community\n```\n\n### Linux (Ubuntu)\n```bash\nwget -qO - https://www.mongodb.org/static/pgp/server-6.0.asc | sudo apt-key add -\nsudo apt-get install -y mongodb-org\nsudo systemctl start mongod\n```\n\n---\n\n## STEP 3: Setup Backend\n\n```bash\n# Navigate to backend directory\ncd backend\n\n# Install dependencies\nnpm install\n\n# Create .env file\ncp .env.example .env\n\n# Edit .env with your configuration\n# Default values:\n# MONGODB_URI=mongodb://localhost:27017/eskom\n# JWT_SECRET=your_jwt_secret_key_here\n# PORT=5000\n# NODE_ENV=development\n\n# Start backend server\nnpm run dev  # or npm start for production\n```\n\nBackend will run on http://localhost:5000\n\n---\n\n## STEP 4: Setup Frontend\n\n```bash\n# Navigate to frontend directory (from root)\ncd frontend\n\n# Install dependencies\nnpm install\n\n# Start frontend development server\nnpm start\n```\n\nFrontend will run on http://localhost:3000\n\n---\n\n## STEP 5: Verify Installation\n\n### Check Backend\n```bash\ncurl http://localhost:5000/api/dashboard\n```\n\nShould return dashboard data\n\n### Check Frontend\nOpen browser and navigate to http://localhost:3000\n\n---\n\n## API Endpoints Reference\n\n### Authentication\n- `POST /api/auth/register` - User registration\n- `POST /api/auth/login` - User login\n\n### Dashboard\n- `GET /api/dashboard` - Get dashboard statistics\n\n### Outages\n- `GET /api/outages` - Get all outages\n- `POST /api/outages` - Create new outage\n- `PATCH /api/outages/:id` - Update outage\n- `DELETE /api/outages/:id` - Delete outage\n\n### Faults\n- `GET /api/faults` - Get all faults\n- `POST /api/faults` - Report fault\n- `PATCH /api/faults/:id` - Update fault\n- `DELETE /api/faults/:id` - Delete fault\n\n### Meters\n- `GET /api/meters` - Get all meters\n- `GET /api/meters/:id` - Get meter by ID\n- `POST /api/meters` - Create meter\n- `PATCH /api/meters/:id` - Update meter\n\n### Customers\n- `GET /api/customers` - Get all customers\n- `GET /api/customers/:id` - Get customer by ID\n- `POST /api/customers` - Create customer\n- `PATCH /api/customers/:id` - Update customer\n- `DELETE /api/customers/:id` - Delete customer\n\n---\n\n## Database Setup\n\n### Create Database\n```bash\n# Connect to MongoDB\nmongo\n\n# Create database\nuse eskom\n\n# Create collections\ndb.createCollection(\"users\")\ndb.createCollection(\"customers\")\ndb.createCollection(\"meters\")\ndb.createCollection(\"outages\")\ndb.createCollection(\"faults\")\ndb.createCollection(\"notifications\")\n\n# Create indexes\ndb.users.createIndex({ email: 1 }, { unique: true })\ndb.customers.createIndex({ email: 1 })\ndb.meters.createIndex({ meterNumber: 1 }, { unique: true })\ndb.outages.createIndex({ createdAt: -1 })\ndb.faults.createIndex({ createdAt: -1 })\n```\n\n---\n\n## Project Structure\n\n```\nEskom-Smart-Electricity-System/\n\u251c\u2500\u2500 frontend/\n\u2502   \u251c\u2500\u2500 running\nmongo --version\n\n# Start MongoDB service\n# Windows: services.msc and start MongoDB\n# Mac: brew services start mongodb-community\n# Linux: sudo systemctl start mongod\n```\n\n### Issue: Port 5000 Already in Use\n**Solution:**\n```bash\n# Find process using port\nlsof -i :5000\n\n# Kill process\nkill -9 <PID>\n\n# Or change port in .env\nPORT=5001\n```\n\n### Issue: Module Not Found\n**Solution:**\n```bash\n# Clear node_modules and reinstall\nrm -rf node_modules package-lock.json\nnpm install\n```\n\n### Issue: CORS Errors\n**Solution:** Ensure both frontend and backend are running and update CORS settings in backend if needed:\n```javascript\napp.use(cors({\n  origin: 'http://localhost:3000',\n  credentials: true\n}));\n```\n\n---\n\n## Production Deployment\n\n### Build Frontend for Production\n```bash\ncd frontend\nnpm run build\n```\n\n### Deploy to Cloud (Example: Heroku)\n```bash\n# Install Heroku CLI\n# Login to Heroku\nheroku login\n\n# Create app\nheroku create your-app-name\n\n# Set environment variables\nheroku config:set MONGODB_URI=your_mongodb_uri\nheroku config:set JWT_SECRET=your_secret\n\n# Deploy\ngit push heroku main\n```\n\n---\n\n##
